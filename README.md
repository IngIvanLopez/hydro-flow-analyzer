# HydroFlow Analyzer

Herramienta para análisis hidrológico básico desarrollada en Python.

## Funcionalidades

- Carga de datos hidrológicos
- Cálculo de métricas básicas de caudal
- Curva de duración de caudales
- Visualización automática

## Tecnologías

- Python
- Pandas
- Matplotlib
- Streamlit

## Uso

Instalar dependencias:

pip install -r requirements.txt

Ejecutar aplicación:

streamlit run app.py

## Aplicación

Permite evaluar rápidamente comportamiento hidrológico a partir de series de caudal.
